About this dashboard

This is a self-directed practice project, not a Wiliot work product. I generated a synthetic 14-day IoT telemetry dataset (~20K pings across 5 zones, 11 bridges, 45 tagged assets) with deliberately injected data-quality issues — a hardware blockage, a duplicate-ingestion burst, signal degradation, network dropouts, a firmware mismatch, and an operational delay — then wrote the queries to detect each one and built this dashboard to visualize the findings.

My goal was to get hands-on with the kind of data quality monitoring, root-cause analysis, and stakeholder reporting this role involves before day one. Happy to walk through the queries, the generator script, or the reasoning behind any of these findings.
